# Documentation

This folder is the maintainer-facing map for `canvas-cli`.

## Contents

- [Architecture overview](architecture.md): system responsibilities and runtime flows
- [Project structure](project-structure.md): source tree guide and placement conventions
- [Development guide](development.md): setup, commands, and change workflow

## When to update these docs

- Update `architecture.md` when core workflows or boundaries change
- Update `project-structure.md` when folders move or new top-level areas are introduced
- Update `development.md` when setup, scripts, or contributor expectations change
- Update `tooling-files.md` when repo-level config files or ignore rules change
